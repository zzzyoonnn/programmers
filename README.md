# 🧩 프로그래머스 문제 풀이

**최적화, 코드 품질, 그리고 점진적인 개선 과정**에 초점을 맞춘 개인 문제 풀이 기록입니다. (Java 기반)

각 문제 풀이에는 다음 내용을 포함합니다:

- **Intuition & Approach** — 문제를 이해한 후 떠올린 초기 접근 방식과 해결 전략
- **Initial Solution** — 처음 작성한 동작하는 코드
- **Complexity Analysis**
  - **Time Complexity** — 시간 복잡도 분석
  - **Space Complexity** — 공간 복잡도 분석
- **Review** — 비효율적인 부분과 병목 지점에 대한 분석
- **Revised Solution** — 개선된 최종 코드 및 최적화 과정 설명

## 🔍 문제 해결 방식

- 먼저 동작하는 코드를 작성한 뒤, 점진적으로 개선합니다.
- 자료구조와 같은 작은 구현 선택이 전체 성능에 큰 영향을 줄 수 있다고 생각합니다.
- 가독성과 효율성을 모두 고려하며, 구조가 좋은 코드는 성능 또한 좋다고 믿습니다.
