# [캐릭터의 좌표](https://school.programmers.co.kr/learn/courses/30/lessons/120861)

## Intuition

캐릭터의 초기 위치는 `(0, 0)`이며, `keyinput`에 주어진 방향에 따라 좌표를 이동한다.

이때 `board`는 `[가로 크기, 세로 크기]`를 나타내므로, 캐릭터가 이동할 수 있는 `x`, `y` 좌표의 최솟값과 최댓값을 계산한 뒤 맵의 범위를 벗어나는 이동은 무시한다.

---

## Approach

1. `board`를 이용하여 캐릭터가 이동할 수 있는 `x`, `y` 좌표의 범위를 계산한다.
2. `keyinput`의 각 방향을 순서대로 확인한다.
3. 이동 후의 좌표가 맵의 범위를 벗어나지 않는 경우에만 캐릭터의 좌표를 변경한다.
4. 모든 이동이 끝난 후 최종 캐릭터의 좌표를 반환한다.

---

## Complexity
### Time Complexity
O(n) - `keyinput`의 모든 방향을 한 번씩 확인한다.

### Space Complexity
O(1) - 캐릭터의 좌표와 이동 범위를 저장하기 위한 고정된 크기의 변수만 사용한다.

---

## My Solution
```
class Solution {
    public int[] solution(String[] keyinput, int[] board) {
        int[] answer = new int[2];
        int[] boundary = new int[4];
        
        int width = board[1] - 1;
        boundary[0] = width / 2;
        boundary[1] = -(width / 2);
        
        int height = board[0] - 1;
        boundary[2] = -(height / 2);
        boundary[3] = height / 2;
        
        for (int i = 0; i < keyinput.length; i++) {
            String direction = keyinput[i];
            
            if (direction.equals("up")) {
                if (answer[1] + 1 > boundary[0]) continue;
                answer[1]++;
            } else if (direction.equals("down")) {
                if (answer[1] - 1 < boundary[1]) continue;
                answer[1]--;
            } else if (direction.equals("left")) {
                if (answer[0] - 1 < boundary[2]) continue;
                answer[0]--;
            } else if (direction.equals("right")) {
                if (answer[0] + 1 > boundary[3]) continue;
                answer[0]++;
            }
        }
        
        return answer;
    }
}
```

---

## Review

전체적으로 `board`의 크기를 기반으로 이동 범위를 계산하고, `keyinput`을 순회하며 맵을 벗어나지 않는 경우에만 좌표를 변경하는 방식으로 문제를 해결했다.

다만 `boundary` 배열은 각 인덱스의 의미를 직접 확인해야 하고, 인덱스가 필요하지 않은 일반 `for`문을 사용하고 있다. 또한 방향별 분기를 `if-else`로 처리하고 있어 가독성 측면에서 개선할 수 있다.

### 핵심 변경 사항
- **반복문 간소화**
  - 인덱스가 필요하지 않으므로 일반 for문을 향상된 for문으로 변경했다.
- **조건문 가독성 개선**
  - 여러 방향을 분기하는 if-else 체인을 switch문으로 변경했다.
- **경계값의 의미 명확화**
  - boundary 배열 대신 minX, maxX, minY, maxY를 사용하여 각 경계값의 의미를 명확하게 표현했다.
- **좌표 이동 로직 단순화**
  - continue를 사용하는 방식에서 이동 가능한 경우에만 좌표를 변경하도록 조건을 작성하여 각 방향의 로직을 한눈에 파악할 수 있도록 했다.

## Revised Solution
````
class Solution {
    public int[] solution(String[] keyinput, int[] board) {
        int[] answer = new int[2];
        
        int height = board[1] - 1;
        int width = board[0] - 1;
        
        int maxX = width / 2;
        int minX = -maxX;
        int maxY = height / 2;
        int minY = -maxY;
        
        for (String direction : keyinput) {
            switch (direction) {
                case "up":
                    if (answer[1] + 1 <= maxY) answer[1]++;
                    break;
                case "down":
                    if (answer[1] - 1 >= minY) answer[1]--;
                    break;
                case "left":
                    if (answer[0] - 1 >= minX) answer[0]--;
                    break;
                case "right":
                    if (answer[0] + 1 <= maxX) answer[0]++;
                    break;
            }
        }
        
        return answer;
    }
}
````
