# [배열 회전시키기](https://school.programmers.co.kr/learn/courses/30/lessons/120844)

## Intuition

배열을 왼쪽 또는 오른쪽으로 한 칸 회전시키는 문제이다.<br>
처음에는 회전을 쉽게 구현하기 위해 `numbers 배열을 두 배로 확장한 뒤, 필요한 구간만 잘라 사용하는 방식으로 접근했다.

---

## Approach

1. 회전 처리를 위해 `numbers` 배열을 두 번 이어붙인 배열을 만든다.
2. 결과를 저장할 `answer` 배열을 생성한다.
3. 회전 방향에 따라 시작 위치를 결정한다.
4. `numbers.length 만큼 순회하며 결과 배열에 값을 채운다.

---

## Complexity
### Time Complexity
O(n) - 배열을 한 번 순회한다.

### Space Complexity
O(n) - 결과 배열과 추가 배열을 생성한다.

---

## My Solution
```
class Solution {
    public int[] solution(int[] numbers, String direction) {
        int[] copy = new int[numbers.length + numbers.length];
        int[] answer = new int[numbers.length];
        
        System.arraycopy(numbers, 0, copy, 0, numbers.length);
        System.arraycopy(numbers, 0, copy, numbers.length, numbers.length);
        
        int temp = direction.equals("right") ? numbers.length - 1 : 1;
        
        for (int i = 0; i < numbers.length; i++) {
                answer[i] = copy[temp + i];
            }
        return answer;
    }
}
```

---

## Review

배열을 두 배로 만들어 회전을 구현했지만, 실제로는 필요한 범위만 접근하므로 메모리를 비효율적으로 사용한다.<br>
또한 `System.arraycopy()`를 두 번 호출하는 과정 역시 불필요한 비용이 발생한다.

이 문제는 배열을 복사하지 않아도, 나머지 연산(`%`)을 이용해 인덱스를 순환시키는 방식으로 더 간결하게 해결할 수 있다.

### 개선 포인트

- 불필요한 2배 크기 배열 제거
- `System.arraycopy()` 제거
- 인덱스를 `%` 연산으로 순환 처리

### 회전 로직

- right → `[0,1,2,3]` → `[3,0,1,2]`
  - 현재 위치 `i`에 들어올 값은 기존 `(i - 1 + n) % n`
- left → `[0,1,2,3]` → `[1,2,3,0]`
  - 현재 위치 `i`에 들어올 값은 기존 `(i + 1) % n`

---

## Revised Solution
````
class Solution {
    public int[] solution(int[] numbers, String direction) {
        int n = numbers.length;
        int[] answer = new int[n];
        
        int direct = direction.equals("right") ? 1 : -1;
        
        for (int i = 0; i < n; i++) {
            answer[i] = numbers[(i - direct + n) % n];
        }
        
        return answer;
    }
}
````

### 핵심 변경 사항
| 항목 | 기존 | 개선        |
|------|------|-----------|
| 공간 복잡도 | O(2n) | O(n)      |
| 배열 복사 | 2회 `System.arraycopy` | 없음        |
| 회전 로직 | 2배 배열 슬라이싱 | `%` 연산 활용 |
| 가독성 | 시작 위치 계산 필요 | 인덱스 순환으로 단순화  |
