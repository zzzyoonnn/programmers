# [공 던지기](https://school.programmers.co.kr/learn/courses/30/lessons/120843)

## Intuition

공 던지기 게임에서는 오른쪽 친구 한 명을 건너뛰고 다음 친구에게 공을 전달한다.<br>
즉, 공을 던질 때마다 순서가 2씩 증가한다는 의미다.

처음에는 이를 그대로 구현하기 위해, 공을 던질 때마다 현재 순서를 2씩 증가시키는 방식으로 접근했다.<br>
`k`번째로 공을 받는 친구를 구해야 하므로, `k - 1`번 동안 순서를 갱신한 뒤 배열의 크기로 나눈 나머지 위치의 친구를 반환한다.

---

## Approach

1. 공을 던지는 친구의 위치를 저장할 `turn 변수를 생성한다.
2. 공이 한 번 전달될 때마다 다음 친구의 위치는 2씩 증가하므로, 반복문을 통해 `turn += 2`를 수행한다.
3. 총 `k - 1`번 이동한 뒤, 배열의 크기로 나눈 나머지 인덱스를 사용해 최종 친구를 반환한다.

---

## Complexity
### Time Complexity
O(k) - `turn` 값을 `k - 1`번 갱신한다.

### Space Complexity
O(1) - 추가적인 자료구조를 사용하지 않는다.

---

## My Solution
```
class Solution {
    public int solution(int[] numbers, int k) {
        int turn = 0;
        for (int i = 1; i < k; i++) { 
            turn += 2;
        }
        return numbers[turn % numbers.length];
    }
}
```

---

## Review

반복문을 통해 공의 이동 위치를 직접 계산했지만,<br>
이동 규칙이 항상 동일하다는 점을 이용하면 수식으로 간단히 표현할 수 있다.

공은 한 번 던질 때마다 인덱스가 2씩 증가하고, 총 `k - 1`번 이동하므로 최종 위치는 다음과 같다.

- (k - 1) * 2

이를 사용하면 반복문 없이 바로 위치를 계산할 수 있어 시간복잡도를 `O(k)`에서 `O(1)`로 개선할 수 있다.

---

## Revised Solution
````
class Solution {
    public int solution(int[] numbers, int k) {
        int turn = (k - 1) * 2;
        return numbers[turn % numbers.length];
    }
}
````

### 핵심 변경 사항
| | 기존               | 개선 |
|---|------------------|---|
| **방식** | 반복문으로 `turn`을 k-1번 누적 | 수식 `(k-1)*2`로 직접 계산 |
| **가독성** | 루프의 의도를 파악해야 함       | 의도가 수식에 드러남 |
| **시간복잡도** | O(k)             | O(1) |
