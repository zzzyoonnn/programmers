# [2016년](https://school.programmers.co.kr/learn/courses/30/lessons/12901)

## Intuition
각 월의 일 수를 저장한 daysInMonth 배열과 요일 정보를 담은 weekDays 배열을 생성한다.<br>
주어진 날짜 이전까지의 총 일수를 계산하기 위해, 해당 월의 직전 월까지의 일수를 모두 더한 뒤 주어진 일(day)을 더한다.<br>
2016년 1월 1일은 금요일이므로, 요일 인덱스를 맞추기 위해 4를 추가로 더한다.<br>
최종적으로 누적된 일수를 7로 나눈 나머지를 이용해 해당 요일을 구한다.

## Approach
1. 월별 일 수를 담은 `daysInMonth` 배열을 생성한다.
2. 요일 정보를 담은 `weekDays` 배열을 생성한다.
3. 날짜의 누적 합을 저장할 `totalDays` 변수를 선언한다.
4. 1월부터 (a - 1)월까지의 일수를 모두 더한다.
5. 주어진 일(day)인 b를 더한다.
6. 2016년 1월 1일이 금요일이므로, 요일 보정을 위해 4를 더한다.
7. `totalDays % 7`을 통해 요일을 계산하고, 해당 인덱스의 값을 반환한다.

## Complexity
### Time Complexity
O(n), 월의 개수만큼 순회한다.

### Space Complexity
O(n), 고정된 배열을 사용한다.

## Code
```
class Solution {
    public String solution(int a, int b) {
        int[] daysInMonth = {0, 31, 29, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        String[] weekDays = {"SUN", "MON", "TUE", "WED", "THU", "FRI", "SAT"};
        
        int totalDays = 0;
        for (int i = 1; i < a; i++) totalDays += daysInMonth[i];
        totalDays += b;
        totalDays += 4;
        return weekDays[totalDays % 7];
    }
}
```


## Review
초기에는 `daysInMonth` 배열을 0번 인덱스부터 사용하면서 직전 월까지의 합을 구하려 했지만, 의도와 다르게 현재 월까지 포함되는 문제가 발생했다.<br>
이를 해결하기 위해 0번째 인덱스에 0을 추가하여, 1번 인덱스부터 월을 매핑하도록 수정했고, 그 결과 원하는 대로 직전 월까지의 합을 정확히 계산할 수 있었다.

또한 다른 풀이를 참고하면서, 자바에서 제공하는 날짜 관련 API를 활용하는 방법도 알게 되었다.

### Calendar.Builder() 방식
특정 날짜를 Calendar 객체로 생성하는 코드
````
Calendar cal = new Calendar.Builder()
    .setCalendarType("iso8601") // ISO 표준 캘린더 사용 (일반적인 우리가 쓰는 달력)
    .setDate(2016, month - 1, day)  // 0부터 시작(e.g. 1월 = 0, 2월 = 1 ...)
    .build();   // 설정한 값으로 Calendar 객체 생성
````
그러나 이 코드만으로는 요일을 반환하지 않기에 `cal.get(Calendar.DAY_OF_WEEK);`를 추가해야 한다.

### LocalDate 방식
````
return LocalDate.of(2016, a, b) // 2016년 a월 b일 날짜 객체 생성
    .getDayOfWeek() // 요일 가져오기
    .toString()
    .substring(0, 3);
````

이로써 직접 계산하는 방식뿐 아니라, 내장 API를 활용하면 보다 간결하고 안정적으로 문제를 해결할 수 있다는 점을 배울 수 있었다.
