# [[1차] 비밀지도](https://school.programmers.co.kr/learn/courses/30/lessons/17681)

## Intuition

주어진 두 정수형 배열을 n자리 2진수 형태의 지도로 변환한다.<br>
각 위치를 비교했을 때 하나라도 벽(`1`)이면 `#`, 둘 다 공백(`0`)이면 공백으로 처리해 최종 지도를 완성한다.

---

## Approach

1. 정수형 배열을 n자리 2진수 문자열로 변환한다.
2. 각 위치의 문자를 비교한다.
3. 하나라도 `1`이면 `#`, 둘 다 `0`이면 공백을 추가한다.
4. 완성된 문자열을 결과 배열에 저장한다.

---

## Complexity
### Time Complexity
O(n²) - n개의 문자열을 생성하고, 각 문자열의 모든 문자를 순회한다.

### Space Complexity
O(n²) - `binary1`, `binary2` 문자열 배열을 추가로 저장한다.

---

## My Solution
```
class Solution {
    public String[] solution(int n, int[] arr1, int[] arr2) {
        String[] binary1 = new String[n];
        String[] binary2 = new String[n];
        
        for (int i = 0; i < n; i++) {
            binary1[i] = String.format("%" + n + "s", Integer.toBinaryString(arr1[i])).replace(' ', '0');
            binary2[i] = String.format("%" + n + "s", Integer.toBinaryString(arr2[i])).replace(' ', '0');
        }
        
        String[] answer = new String[n];
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            sb.setLength(0);
            
            for (int j = 0; j < n; j++) {
                char c1 = binary1[i].charAt(j);
                char c2 = binary2[i].charAt(j);
                
                if (c1 == '1' || c2 == '1') sb.append('#');
                else sb.append(' ');
            }
            
            answer[i] = sb.toString();
        }
        return answer;
    }
}
```

---

## Review

기존 코드는 동작에는 문제가 없지만, 문자열 기반으로 처리하면서 불필요한 변환 과정이 많다.

특히 다음과 같은 과정이 반복되며 추가 비용이 발생한다. 
- `String.format()` 호출
- 2진수 문자열 생성
- 중간 배열(`binary1`, `binary2`) 저장
- 문자 단위 비교

이 문제는 **비트 연산**을 활용하면 훨씬 간결하게 해결할 수 있다.

---

## Revised Solution
````
class Solution {
    public String[] solution(int n, int[] arr1, int[] arr2) {
        String[] answer = new String[n];
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            sb.setLength(0);
            
            int merged = arr1[i] | arr2[i];
            
            for (int j = n - 1; j >= 0; j--) {
                sb.append((merged >> j & 1) == 1 ? '#' : ' ');
            }
            
            answer[i] = sb.toString();
        }
        return answer;
    }
}
````

시간복잡도는 두 코드 모두 O(n²)로 동일하다.
하지만 실제 수행 과정에서는 차이가 있다.

**기존 코드**는 다음의 작업이 반복된다.

1. 문자열 변환
2. `String.format()` 호출
3. 문자 비교

반면 **개선 코드**는 문자열 생성 과정 없이 비트 단위로 직접 처리하기 때문에 실제 실행 비용이 더 적다.

- 비트 OR 연산으로 두 지도를 한 번에 합치고
- 비트 시프트를 통해 필요한 위치의 값만 바로 확인한다.

또한 `binary1`, `binary2` 배열을 제거하면서 추가 메모리 사용도 줄일 수 있다.
- 기존: O(n²)
- 개선: O(n)

### 핵심 변경 사항
| 항목 | 기존 | 개선 |
|------|------|------|
| OR 처리 | 문자 비교(`c1 == '1' \|\| c2 == '1'`) | 비트 OR(`arr1[i] \| arr2[i]`) |
| 중간 배열 | `binary1[]`, `binary2[]` 생성 | 제거 |
| 이진 변환 | `String.format` × 2n번 | 비트 시프트로 대체 |
| 루프 | 이중 루프 × 2 (변환) + 이중 루프 (조합) | 이중 루프 1회 |

## 10진수 <-> 2진수, 8진수, 16진수로 변환하기
### 10진수 -> 2진수, 8진수, 16진수로 변환하기

````
int decimal = 10;

String binary = Integer.toBinaryString(decimal);    // 10진수 -> 2진수
String octal = Integer.toOctalString(decimal);      // 10진수 -> 8진수
String hexaDecimal = Integer.toHexString(decimal);  // 10진수 -> 16진수
````

### 2진수, 8진수, 16진수 -> 10진수

````
int binaryToDecimal = Integer.parseInt("1010", 2);
int octalToDecimal = Integer.parseInt("12", 8);
int hexaToDecimal = Integer.parseInt("A", 16);
````

## 비트 연산 정리

| 연산 | 기호 | 설명 | 이 문제에서 |
|------|------|------|------------|
| AND | `&` | 둘 다 1이어야 1 | - |
| OR | `\|` | 하나라도 1이면 1 | 핵심: 두 지도 합치기 |
| XOR | `^` | 다를 때 1 | - |
| NOT | `~` | 비트 반전 | - |
| 왼쪽 시프트 | `<<` | 비트를 왼쪽으로 이동 (×2) | - |
| 오른쪽 시프트 | `>>` | 비트를 오른쪽으로 이동 (÷2) | j번째 비트 추출 |

### 예시

````
int merged = arr1[i] | arr2[i];
// arr1[i] = 0b1010, arr2[i] = 0b1100
// merged = 0b1110 ← 한 번에 OR 처리

(merged >> j) & 1
// j=3: 1110 >> 3 = 0001, & 1 = 1 → '#'
// j=2: 1110 >> 2 = 0011, & 1 = 1 → '#'
// j=1: 1110 >> 1 = 0111, & 1 = 1 → '#'
// j=0: 1110 >> 0 = 1110, & 1 = 0 → ' '
````
