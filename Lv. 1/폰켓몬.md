# 폰켓몬
[폰켓몬](https://school.programmers.co.kr/learn/courses/30/lessons/1845?language=java)

## Intuition
선택할 수 있는 폰켓몬의 최대 개수는 전체 배열 길이의 절반이다.
같은 종류의 폰켓몬은 중복 선택할 수 없으므로, 종류의 개수가 핵심이다.

따라서 중복을 제거할 수 있는 HashSet을 사용해 폰켓몬의 종류 수를 구한다.
이후, 선택 가능한 최대 개수와 종류 수 중 더 작은 값을 반환한다.

## Approach
1. 선택 가능한 폰켓몬 수를 nums.length / 2로 계산한다.
2. HashSet을 사용해 폰켓몬의 종류를 저장한다.
3. 배열을 순회하며 set에 값을 추가한다.
4. set.size()와 선택 가능한 개수 중 최솟값을 반환한다.

## Complexity
### Time Complexity
O(n), 배열을 한 번 순회하며 HashSet에 삽입하기 때문이다.

### Space Complexity
O(n), 최악의 경우 모든 원소가 서로 다른 종류일 수 있다.

## Review
조건문 없이 Math.min()을 사용하면 더 간결하게 구현할 수 있다.
불필요한 분기 없이 의도를 명확하게 표현할 수 있는 점이 인상적이었다.

## Code
```
import java.util.*;

class Solution {
    public int solution(int[] nums) {
        int answer = 0;
        int maxSelect = nums.length / 2;
        
        HashSet<Integer> set = new HashSet<>();
        for (int num : nums) {
            set.add(num);
        }
        
        return Math.min(set.size(), maxSelect);
    }
}
```
