# [최빈값 구하기](https://school.programmers.co.kr/learn/courses/30/lessons/120812)

## Intuition
최빈값을 구하기 위해 `HashMap`을 사용한다.<br>
Key에는 값, Value에는 해당 값의 등장 횟수를 저장한다.

가장 많이 등장한 빈도수를 기준으로 최빈값을 결정하며,<br>
최빈값이 여러 개 존재할 경우 `-1`을 반환한다.
---

## Approach
1. 배열을 순회하며 각 값의 빈도수를 `HashMap에 저장한다.
2. `map`을 순회하며 가장 큰 빈도수(`max)를 찾는다.
3. 다시 `map`을 순회하며 `max`와 동일한 빈도수를 가진 값을 찾는다.
4. 해당 값이 여러 개라면 `-1을 반환한다.

---

## Complexity
### Time Complexity
O(n), 배열과 map을 순회한다.(상수 번)

### Space Complexity
O(n), 최악의 경우 모든 값이 다를 때 map에 저장한다.

---

## My Solution
```
import java.util.*;

class Solution {
    public int solution(int[] array) {
        HashMap<Integer, Integer> map = new HashMap<>();
        for (int i : array) {
            map.put(i, map.getOrDefault(i, 0) + 1);
        }
        
        int max = -1;
        for (Integer key : map.keySet()) {
            max = Math.max(max, map.get(key));
        }
        
        int answer = -1;
        for (Integer key : map.keySet()) {
            if(map.get(key) == max) {
                if (answer != -1) {
                    answer = -1;
                    break;
                }
                answer = key;
            }
        }
        return answer;
    }
}
```

---

## Review
현재 구현은 `map`을 여러 번 순회하여 최빈값을 찾는다.<br>
동작에는 문제가 없지만, 순회 횟수가 많고 `get()` 호출이 반복되는 점이 아쉽다.

특히 `keySet()`을 사용하면 key를 기준으로 순회한 뒤<br>
다시 `get()`으로 값을 조회해야 하므로 비효율적일 수 있다.

### 개선 포인트
| 항목 | 기존 | 개선 |
|------|------|------|
| 맵 순회 횟수 | 3번 | 2번 (빈도 집계 1번 + 최빈값 탐색 1번) |
| 맵 조회 방식 | `keySet()` + `get()` | `entrySet()` (조회 1회로 단축) |
| max/answer 탐색 | 루프 2개 분리 | 루프 1개로 통합 |

## Revised Solution
````
import java.util.*;

class Solution {
    public int solution(int[] array) {
        HashMap<Integer, Integer> map = new HashMap<>();
        for (int num : array) {
            map.put(num, map.getOrDefault(num, 0) + 1);
        }

        int maxCount = -1;
        int answer = -1;

        for (Map.Entry<Integer, Integer> entry : map.entrySet()) {
            int key = entry.getKey();
            int count = entry.getValue();

            if (count > maxCount) {
                maxCount = count;
                answer = key;
            } else if (count == maxCount) {
                answer = -1;
            }
        }

        return answer;
    }
}
````
`entrySet()`을 사용해 key와 value를 동시에 처리하면서 더 효율적이고 간결한 코드가 되었다.
