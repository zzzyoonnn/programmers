# [정수 내림차순으로 배치하기](https://school.programmers.co.kr/learn/courses/30/lessons/12933)

## Intuition
정수 `n`의 각 자릿수를 분리하여 정렬한 뒤, 다시 하나의 수로 조합하면 된다.<br>
이를 위해 `ArrayList<Integer>`를 사용하여 자릿수를 저장하고, 내림차순으로 정렬한 후 문자열로 변환하여 `long` 타입으로 반환한다.
---

## Approach
1. 각 자릿수를 저장할 리스트를 생성한다.
2. `n % 10`을 통해 자릿수를 하나씩 추출하여 리스트에 저장한다.
3. 리스트를 내림차순으로 정렬한다.
4. 정렬된 값을 순회하며 문자열로 변환한다.
5. 문자열을 `long`으로 변환하여 반환한다.

---

## Complexity
### Time Complexity
O(n log n), n은 자릿수의 개수이며 정렬(Collections.sort)이 지배적이므로 n log n이다.

### Space Complexity
O(n), 자릿수를 저장하는 리스트를 사용한다.

---

## My Solution
```
import java.util.*;

class Solution {
    public long solution(long n) {
        long answer = 0;
        ArrayList<Integer> list = new ArrayList<>();
        
        while (n > 0) {
            list.add((int)(n % 10));
            n /= 10;
        }
        
        Collections.sort(list, Collections.reverseOrder());
        
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < list.size(); i++) sb.append(list.get(i));
        
        return Long.parseLong(sb.toString());
    }
}
```

## Revised Solution
### char 배열 + 정렬
````
import java.util.*;

class Solution {
    public long solution(long n) {
        char[] arr = String.valueOf(n).toCharArray();
        Arrays.sort(arr);
        
        StringBuilder sb = new StringBuilder(new String(arr));
        return Long.parseLong(sb.reverse().toString());
    }
}
````
- 장점
  - 가장 빠른 방식 (코딩 테스트 기준 최적)
  - 불필요한 객체 생성이 거의 없음
  - 직관적인 흐름 (문자 변환 → 정렬 → 뒤집기)
- 단점
  - `reverse()` 과정이 추가됨 (하지만 비용은 매우 작음)

### Stream + 람다
````
import java.util.*;
import java.util.stream.*;

class Solution {
    public long solution(long n) {
        return Long.parseLong(
                  String.valueOf(n)     // 숫자를 문자열로 변환
                        .chars()        // 각 문자를 IntStream으로 변환
                        .boxed()        // Stream<Integer>로 boxing
                        .sorted(Comparator.reverseOrder())
                        .map(c -> String.valueOf(           // 문자로 변환
                                    (char) c.intValue()))   // 문자열 합치기
                        .collect(Collectors.joining())
                );
    }
}
````
- 장점
  - 함수형 스타일로 표현 가능
  - 내림차순 정렬 의도가 명확하게 드러남
- 단점
  - 성능 저하 (boxing + 객체 생성 비용)
  - 불필요한 변환 과정 많음
  - 가독성이 오히려 떨어질 수 있음
  - 디버깅이 상대적으로 어려움


### 비교
두 코드 모두 **O(log n, log(log n))** 이지만,
stream은 boxing/Stream 생성 비용으로 **상수 계수(constant factor)가 더 크다.**

| 항목     | 배열 | 스트림 |
| ------ | -- | --- |
| 시간     | 빠름 | 느림  |
| 메모리    | 적음 | 많음  |
| 객체 생성  | 거의 없음 | 많음  |
| 정렬 방식 | `Arrays.sort()` (Dual-Pivot Quicksort) | Stream `sorted()` (TimSort + boxing 오버헤드) |
| boxing | 없음 | `char → Integer` boxing 발생 |
| 객체 생성 | 최소화 | Stream, Optional 등 다수 생성 |
| 역순 처리 | `sb.reverse()` (제자리 연산) | `reverseOrder()` Comparator 비교 |
