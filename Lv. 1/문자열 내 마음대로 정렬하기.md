# [문자열 내 마음대로 정렬하기](https://school.programmers.co.kr/learn/courses/30/lessons/12915)

## Intuition
문자열의 특정 인덱스(`n`)에 위치한 문자를 기준으로 정렬해야 한다.<br>
이를 위해 각 문자를 기준으로 문자열을 분류할 수 있는 자료구조를 활용한다.

알파벳은 총 26개이므로, 각 문자를 인덱스로 사용하는 `ArrayList` 배열을 만들어 해당 위치의 문자를 기준으로 문자열을 그룹화한다.

---

## Approach
1. 알파벳(26개)을 기준으로 `ArrayList<String>[] list` 배열을 생성한다.
2. 각 문자열의 `n`번째 문자를 기준으로, 해당 알파벳 인덱스에 문자열을 저장한다.
3. 배열을 순회하며 비어있지 않은 리스트를 사전순으로 정렬한다.
4. 정렬된 문자열을 순서대로 결과 배열에 다시 담는다.

---

## Complexity
### Time Complexity
O(N log N), 각 리스트 내부에서 정렬이 발생한다.

### Space Complexity
O(n), 문자열을 리스트에 저장한다.

---

## My Solution
```
import java.util.*;

class Solution {
    public String[] solution(String[] strings, int n) {
        ArrayList<String>[] list = new ArrayList[26];
        for (int i = 0; i < 26; i++) list[i] = new ArrayList<>();

        for (int i = 0; i < strings.length; i++) {
            char c = strings[i].charAt(n);
            list[c - 'a'].add(strings[i]);
        }

        int index = 0;
        for (int i = 0; i < 26; i++) {
            if (!list[i].isEmpty()) {
                Collections.sort(list[i]);
                for (int j = 0; j < list[i].size(); j++) {
                    strings[index++] = list[i].get(j);
                }
            }
        }
        return strings;
    }
}
```

---

## Review
문제의 핵심은 **n번째 문자 기준 정렬 + 같으면 사전순 정렬**이다.

위 방식은 이를 직접 구현한 방법이지만, 자바에서는 `람다식과 Comparator를 활용`하면 더 간결하게 해결할 수 있다.

````
if(a.charAt(n) == b.charAt(n)) {
    return a.compareTo(b);
}
````

## Revised Solution
````
import java.util.*;

class Solution {
    public String[] solution(String[] strings, int n) {
        Arrays.sort(strings, (a, b) -> {
            if(a.charAt(n) == b.charAt(n)) {
                return a.compareTo(b);
            }
            return a.charAt(n) - b.charAt(n);
        });
        
        return strings;
    }
}
````
Comparator를 사용하면 정렬 기준만 정의하여 훨씬 직관적으로 문제를 해결할 수 있다.
