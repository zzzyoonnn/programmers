# [제일 작은 수 제거하기](https://school.programmers.co.kr/learn/courses/30/lessons/12935)

## Intuition

반환해야 하는 배열의 길이가 1이라면, 최솟값을 제거했을 때 빈 배열이 되므로 `-1`을 반환해야 한다.<br>
따라서 먼저 배열의 길이를 확인하고, 길이가 1인 경우 바로 `[-1]`을 반환한다.

이후에는 배열에서 최솟값을 구한 뒤, 해당 값을 제외한 새로운 배열을 만들어 반환한다.

---

## Approach

1. 배열의 길이가 1이면 `[-1]`을 반환한다.
2. 배열을 순회하며 최솟값을 구한다.
3. 다시 배열을 순회하면서 최솟값을 제외한 값들로 새로운 배열을 생성한다.

---

## Complexity
### Time Complexity
O(n), 배열을 두 번 순회하지만, 각각 O(n)이므로 전체는 O(n)이다.

### Space Complexity
O(n), 최솟값을 제거한 새로운 배열을 생성한다.

---

## My Solution
```
class Solution {
    public int[] solution(int[] arr) {
        if (arr.length == 1) return new int[]{-1};
        
        int min = Integer.MAX_VALUE;
        for (int num : arr) {
            min = Math.min(min, num);
        }
        
        int index = 0;
        int[] answer = new int[arr.length - 1];
        for (int num : arr) {
            if (num == min) continue;
            answer[index++] = num;
        }
        return answer;
    }
}
```

---

## Review
시간복잡도는 O(n)으로 효율적으로 잘 작성되어 있다. 다만 `System.arraycopy()`를 사용하면 다음과 같이 개선할 수 있다.
- 최솟값 자체가 아니라 **인덱스를 저장**하여 불필요한 값 비교를 줄였다.
- `System.arraycopy()`를 사용해 JVM 네이티브 메모리 복사로 더 빨라졌다.
- 조건 분기(`if (num == min)`)가 사라져 코드 흐름이 더 단순해졌다.

---

## Revised Solution
````
class Solution {
    public int[] solution(int[] arr) {
        if (arr.length == 1) return new int[]{-1};
        
        int minIndex = 0;
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] < arr[minIndex]) minIndex = i;
        }
        
        int[] answer = new int[arr.length - 1];
        System.arraycopy(arr, 0, answer, 0, minIndex);
        System.arraycopy(arr, minIndex + 1, answer, minIndex, arr.length - minIndex - 1);
        return answer;
    }
}
````

---

## System.arraycopy 정리
기본 문법
````
System.arraycopy(src, srcPos, dest, destPos, length);
````

| 파라미터 | 설명 |
|----------|------|
| `src` | 복사할 원본 배열 |
| `srcPos` | 원본 배열의 시작 인덱스 |
| `dest` | 복사 대상 배열 |
| `destPos` | 대상 배열의 시작 인덱스 |
| `length` | 복사할 요소 개수 |

### 빠른 이유

- JVM의 네이티브 메서드로 구현되어 있어 **C 수준의 메모리 복사**를 수행한다.
- 반복문보다 오버헤드가 적다.
- 내부적으로 `memmove` 계열 최적화를 사용한다.

### 자주 쓰이는 패턴

1\. 특정 인덱스 요소 제거
```
// arr에서 minIndex 위치의 요소를 제거
int[] answer = new int[arr.length - 1];
System.arraycopy(arr, 0, answer, 0, minIndex);                          // 앞 블록
System.arraycopy(arr, minIndex + 1, answer, minIndex, arr.length - minIndex - 1); // 뒷 블록
```

2\. 배열 복사
```
int[] copy = new int[arr.length];
System.arraycopy(arr, 0, copy, 0, arr.length);
```

3\. 배열 이어 붙이기
```
int[] merged = new int[a.length + b.length];
System.arraycopy(a, 0, merged, 0, a.length);
System.arraycopy(b, 0, merged, a.length, b.length);
```

4\. 배열 일부 이동 (shift)
```
// 인덱스 i 이후 요소를 한 칸 앞으로 당기기
System.arraycopy(arr, i + 1, arr, i, arr.length - i - 1);
```
