# [예산](https://school.programmers.co.kr/learn/courses/30/lessons/12982)

## Intuition

배열을 오름차순으로 정렬한 뒤, 예산이 허용하는 범위 내에서 작은 금액부터 차례대로 지원한다.<br>
최대한 많은 부서를 지원하려면 비용이 적은 요청부터 처리하는 것이 유리하다.

---

## Approach

1. 배열을 오름차순으로 정렬한다.
2. 작은 금액부터 순회하며 예산에서 차감한다.
3. 현재 요청 금액이 남은 예산보다 크다면 반복을 종료한다.
4. 지원 가능한 부서 수를 반환한다.

---

## Complexity
### Time Complexity
O(n log n) - 배열 정렬에 가장 많은 시간이 소요된다.

### Space Complexity
O(1) - 추가적인 자료구조를 사용하지 않는다.

---

## My Solution
```
import java.util.*;

class Solution {
    public int solution(int[] d, int budget) {
        Arrays.sort(d);
        
        int index = 0;
        while (index < d.length && d[index] <= budget) {
            budget -= d[index++];
        }
        
        return index;
    }
}
```

---

## Review

- `index`는 위치의 의미가 강하므로, 실제 역할을 드러내는 `count`가 더 적절하다.
- `while` 문보다 `for-each` 문이 “배열을 순차적으로 순회한다”는 의도를 더 명확하게 표현한다.
- 조기 종료 조건을 `break`로 분리하면 흐름을 읽기 쉽다.

---

## Revised Solution
````
import java.util.*;

class Solution {
    public int solution(int[] d, int budget) {
        Arrays.sort(d);
        
        int count = 0;
        for (int cost : d) {
            if (cost > budget) break;
            budget -= cost;
            count++;
        }
        
        return count;
    }
}
````

| 항목     | 기존                 | 개선                        |
| ------ | ------------------ | ------------------------- |
| 변수명    | `index` — 위치 중심 표현 | `count` — 지원한 부서 수를 직접 표현 |
| 반복문    | `while` + 후위 증가 연산 | `for-each`로 순회 의도 명확화     |
| 종료 조건  | 반복 조건식 내부 처리       | `if ... break`로 흐름 분리     |
| 가독성    | 한 줄에 여러 동작 포함      | 역할별로 분리해 이해하기 쉬움          |
| 시간 복잡도 | O(n log n)         | O(n log n)                |
| 공간 복잡도 | O(1)               | O(1)                      |
