# [분수의 덧셈](https://school.programmers.co.kr/learn/courses/30/lessons/120808)

## Intuition
기본적인 `분수 덧셈 공식`을 활용하여 두 분수를 더한 뒤, `최대공약수`를 이용해 기약분수로 변환한다.

---

## Approach
1. 첫 번째 분자와 두 번째 분모를 곱하고, 두 번째 분자와 첫 번째 분모를 곱한 값을 더해 새로운 분자를 구한다.
2. 두 분모를 곱하여 새로운 분모를 구한다.
3. 유클리드 호제법을 이용해 분자와 분모의 최대공약수를 구한다.
4. 분자와 분모를 최대공약수로 나누어 기약분수로 만든 뒤 배열에 담아 반환한다.

---

## Complexity
### Time Complexity
O(log n), 최대공약수 계산 (유클리드 호제법)

### Space Complexity
O(log n), 재귀 호출 스택 사용

---

## Code
```
class Solution {
    public int[] solution(int numer1, int denom1, int numer2, int denom2) {
        int numerator = (numer1 * denom2) + (numer2 * denom1);
        int denominator = denom1 * denom2;
        
        int gcd = gcd(numerator, denominator);
        
        return new int[]{numerator / gcd, denominator / gcd};
    }
    
    public static int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }
}
```

---

## Review
변수명을 numerator와 denominator로 변경하여 분수 연산의 의미를 보다 명확하게 표현했다.<br>
또한 불필요한 Math.max, Math.min 사용과 사용하지 않는 메서드를 제거하여 코드의 가독성과 간결함을 개선했다.

---

## 유클리드 호제법
큰 수를 작은 수로 나눈 나머지로 계속 바꾸는 두 수의 최대공약수(GCD)를 빠르게 구하는 알고리즘
````
gcd(a, b) = gcd(b, a % b)
````
gcd(큰 수, 작은 수) → gcd(작은 수, 나머지)로 바꿔가며 반복하며 **나머지가 0이 되는 순간, 그때의 값이 최대공약수**가 된다.

### 시간 복잡도
O(log n)
