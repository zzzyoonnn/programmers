# [게임 맵 최단거리](https://school.programmers.co.kr/learn/courses/30/lessons/1844)

## Intuition
격자 형태의 맵에서 (0, 0)부터 (rows-1, cols-1)까지의 **최단 거리**를 구하는 문제이므로 BFS를 사용한다.<br>
탐색에 필요한 행과 열의 크기(`rows`, `cols`)와 방문 여부를 저장할 `visited` 배열을 선언한다.

또한, 상하좌우 이동을 위한 방향 배열 `dx`, `dy`를 정의하고,<br>
좌표와 이동 거리를 함께 관리하기 위해 `Pos` 클래스를 사용한다.

---

## Approach
1. 맵의 크기를 기반으로 `rows`, `cols`, `visited` 배열을 초기화한다.
2. 시작 지점(0, 0)을 큐에 넣고 BFS 탐색을 시작한다.
3. 현재 위치에서 상하좌우로 이동 가능한 좌표를 확인한다.
4. 맵 범위 내에 있고, 방문하지 않았으며, 이동 가능한 칸(`maps[nx][ny] == 1`)인 경우 큐에 추가한다.
5. 목표 지점에 도달하면 이동 거리를 반환한다.
6. 끝까지 도달하지 못하면 -1을 반환한다.

---

## Complexity
### Time Complexity
O(m * n), 각 좌표를 한 번씩만 방문한다.

### Space Complexity
O(m * n), `visited` 배열과 BFS 큐를 사용한다.

---

## My Solution
```
import java.util.*;

class Solution {
    
    static int rows, cols;
    static boolean[][] visited;
    static int[] dx = {1, -1, 0, 0}, dy = {0, 0, 1, -1};
    
    static class Pos {
        int x, y, dist;
        
        Pos(int x, int y, int dist) {
            this.x = x;
            this.y = y;
            this.dist = dist;
        }
    }
    
    public int solution(int[][] maps) {
        rows = maps.length;
        cols = maps[0].length;
        
        visited = new boolean[rows][cols];
        
        return bfs(new Pos(0, 0, 1), maps);
    }
    
    public static int bfs(Pos pos, int[][] maps) {
        visited[pos.x][pos.y] = true;
        Queue<Pos> queue = new LinkedList<>();
        queue.add(pos);
        
        while (!queue.isEmpty()) {
            Pos cur = queue.poll();
            
            int x = cur.x;
            int y = cur.y;
            int dist = cur.dist;
            
            visited[x][y] = true;
            
            if (x == rows - 1 && y == cols - 1) return dist;
            
            for (int k = 0; k < 4; k++) {
            int nx = x + dx[k];
            int ny = y + dy[k];
            
                if (isInBounds(nx, ny) && !visited[nx][ny] && maps[nx][ny] == 1) {
                    queue.add(new Pos(nx, ny, dist + 1));
                }
            }
        }
        return -1;
    }
    
    private static boolean isInBounds(int x, int y) {
        return x >= 0 && x < rows && y >= 0 && y < cols;
    }
}
```

## Review
정확성 테스트는 통과했지만, 효율성 테스트에서 실패했다.

원인은 **방문 처리 시점**에 있었다.<br>
기존 코드에서는 큐에서 꺼낸 뒤 방문 처리를 했기 때문에, 동일한 좌표가 큐에 여러 번 들어갈 수 있었다.<br>
이로 인해 큐의 크기가 불필요하게 증가하면서 시간초과가 발생했다.
````
if (isInBounds(nx, ny) && !visited[nx][ny] && maps[nx][ny] == 1) {
    queue.add(new Pos(nx, ny, dist + 1));
}
````
이를 해결하기 위해, **큐에 넣는 시점에 바로 방문 처리**를 수행하도록 수정했다.
이렇게 하면 동일한 노드의 중복 탐색을 방지할 수 있다.
