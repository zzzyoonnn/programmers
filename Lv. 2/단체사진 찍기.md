# [단체사진 찍기](https://school.programmers.co.kr/learn/courses/30/lessons/1835)

## Intuition
8명의 프렌즈를 일렬로 배치하면서, 주어진 조건을 모두 만족하는 경우의 수를 구하는 문제이다.<br>
가능한 모든 배치를 탐색해야 하므로 순열을 기반으로 접근하며, 단순 완전탐색 대신 **DFS와 백트래킹을 이용해 불필요한 탐색을 줄인다.**

특히 두 프렌즈가 모두 배치된 시점에서 조건을 검사하고, 조건을 만족하지 않으면 더 이상 탐색하지 않고 가지치기를 수행한다.

---

## Approach
1. DFS를 이용해 8명의 순열을 생성한다.
2. 각 단계에서 현재까지 배치된 상태를 기준으로 조건을 검사한다.
   - 조건에 등장하는 두 프렌즈가 모두 배치된 경우에만 검사한다.
   - 조건을 만족하지 않으면 해당 경로는 더 이상 탐색하지 않는다. (가지치기)
3. 모든 프렌즈가 배치된 경우(깊이 8)에 도달하면 정답을 증가시킨다.

---

## Complexity
### Time Complexity
O(n), 최악의 경우 모든 순열을 탐색한다.

### Space Complexity
O(m * n), `visited` 배열과 `arr` 배열을 사용하고 재귀 호출을 사용한다.

## My Solution
```
class Solution {
    static char[] friends = {'A', 'C', 'F', 'J', 'M', 'N', 'R', 'T'};
    static boolean[] visited = new boolean[8];
    static char[] arr = new char[8];
    static int answer;
    
    public int solution(int n, String[] data) {
        answer = 0;
        dfs(0, data);
        return answer;
    }
    
    void dfs(int depth, String[] data) {
        if (depth == 8) {
            answer++;
            return;
        }
        
        for (int i = 0; i < 8; i++) {
            if (!visited[i]) {
                visited[i] = true;
                arr[depth] = friends[i];
                
                if (isValid(depth, data)) {
                    dfs(depth + 1, data);
                }
                
                visited[i] = false;
            }
        }
    }
    
    boolean isValid(int depth, String[] data) {
        for (String cur : data) {
            char a = cur.charAt(0);
            char b = cur.charAt(2);
            char op = cur.charAt(3);
            int dist = cur.charAt(4) - '0';
            
            int posA = -1, posB = -1;
            
            for (int i = 0; i <= depth; i++) {
                if (arr[i] == a) posA = i;
                if (arr[i] == b) posB = i;
            }
            
            if (posA == -1 || posB == -1) continue;
            
            int gap = Math.abs(posA - posB) - 1;
            
            if (op == '=' && gap != dist) return false;
            if (op == '<' && gap >= dist) return false;
            if (op == '>' && gap <= dist) return false;
        }
        return true;
    }
}
```

## Review
기존 구현에서는 조건을 검사할 때마다 두 프렌즈의 위치를 찾기 위해 배열을 선형 탐색했다.
````
for (int i = 0; i <= depth; i++) {
    if (arr[i] == a) posA = i;
    if (arr[i] == b) posB = i;
}
````

이 방식은 조건 하나를 검사할 때마다 최대 O(8)의 시간이 소요되며,<br>
조건의 개수가 많아질수록 동일한 탐색이 반복되어 비효율적이다.

이를 개선하기 위해 **각 프렌즈의 현재 위치를 별도의 배열에 저장하는 방식**을 적용했다.

````
int[] pos = new int[26];
````
- pos['A' - 'A'] 형태로 접근하여 각 프렌즈의 위치를 O(1)에 조회할 수 있다.
- DFS 과정에서 배치 시 위치를 기록하고, 백트래킹 시 원상복구한다.

## Revised Solution
````
import java.util.*;

class Solution {

    static char[] friends = {'A','C','F','J','M','N','R','T'};
    static boolean[] visited;
    static char[] arr;
    static int[] pos;
    static int answer;

    public int solution(int n, String[] data) {
        answer = 0;
        visited = new boolean[8];
        arr = new char[8];
        pos = new int[26];
        
        Arrays.fill(pos, -1);

        dfs(0, data);
        return answer;
    }

    void dfs(int depth, String[] data) {
        if (depth == 8) {
            answer++;
            return;
        }

        for (int i = 0; i < 8; i++) {
            if (!visited[i]) {
                visited[i] = true;
                arr[depth] = friends[i];
                pos[friends[i] - 'A'] = depth;

                if (isValid(data)) {
                    dfs(depth + 1, data);
                }

                pos[friends[i] - 'A'] = -1;
                visited[i] = false;
            }
        }
    }

    boolean isValid(String[] data) {
        for (String cur : data) {
            char a = cur.charAt(0);
            char b = cur.charAt(2);
            char op = cur.charAt(3);
            int dist = cur.charAt(4) - '0';

            int posA = pos[a - 'A'];
            int posB = pos[b - 'A'];

            if (posA == -1 || posB == -1) continue;

            int gap = Math.abs(posA - posB) - 1;

            if (op == '=' && gap != dist) return false;
            if (op == '<' && gap >= dist) return false;
            if (op == '>' && gap <= dist) return false;
        }
        return true;
    }
}
````

### 개선 효과
- 시간 복잡도 개선
    - 위치 탐색: O(depth) → O(1)
- 중복 연산 제거
    - 동일한 위치 탐색을 반복하지 않도록 개선
- 코드 단순화
    - depth 기반 탐색이 필요 없어져 isValid 함수의 책임이 명확해짐
